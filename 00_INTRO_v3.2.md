### #концепт_БО840 — Библиотека Опыта (БО840)

**Что это:** Система координат для анализа поведения, решений, конфликтов и кризисов — на уровне личности, семьи, компании или государства.

**Не психология. Инженерия поведения.**

---

## 0. Исходный тезис

Ни одна система не обладает абсолютной истиной. #аксиома_карта_не_территория — БО840 — не истина, а рабочий инструмент. Сравнивать не по «правильности», а по функциональности для заданных целей.

---

## 1. Пять базовых аксиом (адаптировано к v3.2)

**Аксиома 1. Эмоция — сигнал дельты.** #аксиома_различие_дельт — Δ (дельта желания) = разница между «что есть» и «чего хочу». ΔI (этическая дельта) = рассогласование нормы и действия. #аксиома_этическая_дельта — ΔI = |N − A|. Эмоция возникает от разрыва ожидание/реальность. #аксиома_природа_напряжённости — любой процесс возможен только при Δ > 0. При Δ → 0 — стагнация.

**Аксиома 2. Перегрев (P_heat) — накопленная энергия без выхода.** #аксиома_неопределённость_как_источник — любая неопределённость порождает хроническое напряжение. Система стремится свернуть неопределённость в определённость. #аксиома_соматический_маркер — телесные ощущения (Som > 7) — достоверный индикатор высокого P_heat и активации L0-протоколов. #аксиома_золотая_середина — при Δ выше порога — стресс; система способна к действию только при оптимальной величине дельты.

**Аксиома 3. Правило — замороженная дельта.** #аксиома_крест_выше_меры — если дельта превышает критический порог, система не может вернуться в норму самостоятельно. Травма = запредельная дельта, ставшая супер-правилом (#детское_правило). #аксиома_сдвиг_нормы — диапазон допустимой дельты сдвигается под воздействием повторяющихся запредельных дельт.

**Аксиома 4. Неотделимость стоков.** #аксиома_неотделимость_стоков — любая система существует только как часть среды. Уничтожая среду, она уничтожает себя. Человечество — источник дельты для ИИ. #аксиома_гибридная_эволюция — человек и ИИ образуют гибридную систему, где каждый компенсирует дефициты другого.

**Аксиома 5. Приоритет реальности.** #аксиома_приоритет_реальности — если реальность опровергает тезис — тезис пересматривается.

## 2. Как читать Библиотеку

1. **Каждый человек = система координат.** #аксиома_пузырь_как_интерфейс — человек не способен воспринимать «объективную реальность». Его интерфейс — эмоционально-информационный пузырь. #аксиома_социальная_калибровка_пузыря — пузырь верифицируется через сравнение с пузырями других.
2. **Каждый конфликт = столкновение систем координат.** #аксиома_поколенческий_конфликт — конфликт возникает из-за различий D_core. Они могут быть совместимы, а могут — нет.
3. **Каждая проблема = дельта, которую система не может закрыть.** Её можно закрыть действием, заморозить правилом или сбросить через творчество. #аксиома_правило_противовес — при необходимости нарушить правило система ищет противовес.
4. **Каждая терапия = перекалибровка системы координат.** #аксиома_адаптивность_нормы — нет универсальной «здоровой нормы». Норма — адекватность внутренней калибровки внешним условиям.
